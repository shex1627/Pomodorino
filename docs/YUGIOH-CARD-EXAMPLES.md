## Implementation Notes

### Card Generation Logic:
1. **Task Type determines base template:**
   - Learning tasks → Spellcaster/Warrior types
   - Cooking tasks → Beast-Warrior/Warrior with FIRE
   - Coding tasks → Machine/Spellcaster with LIGHT/DARK
   - Home improvement → Machine with WATER/EARTH

2. **Stats based on performance:**
   - Quiz Score % → ATK value (75% = 2100, 100% = 2800)
   - Task difficulty → Star Level (easy = 4-5, hard = 7-9)
   - Time spent → DEF value

3. **Attribute based on interest category:**
   - FIRE: Cooking, hot/fast activities
   - WATER: Plumbing, flow-based topics
   - EARTH: Building, construction, gardening
   - WIND: Travel, communication, speed
   - LIGHT: AI, knowledge, learning
   - DARK: Deep technical, system-level

4. **Card effects reference the task:**
   - Cooking cards have food/recipe-themed effects
   - AI cards have memory/data-themed effects
   - Action items get stronger effects than learning tasks

### Art Generation Prompt Template:
```
Create a Yu-Gi-Oh! trading card illustration in official anime
art style: [CHARACTER DESCRIPTION], [POSE/ACTION], [ENVIRONMENT],
[COLOR PALETTE]. Style requirements: bold black outlines, dynamic
composition, dramatic lighting, fantasy aesthetic, highly detailed,
official TCG quality, vibrant colors, epic atmosphere.
```
